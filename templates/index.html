What Is Virtual Memory?

Virtual memory is an essential OS technique that creates an illusion of having more memory than physically available. It maps virtual addresses to physical locations and swaps pages between RAM and disk as needed.

Paging

Physical memory is divided into fixed-size blocks called frames. Virtual memory is divided into same-size blocks called pages. The OS maintains a page table that maps virtual pages to physical frames.

Page Faults

When a process accesses a page that isn't in physical memory, a page fault occurs. The OS must load the page from disk. If RAM is full, it must choose a victim page to evict first.

Page Replacement

When all frames are occupied, the OS uses a page replacement algorithm to decide which existing page to evict. The goal: minimize faults and keep frequently-used pages in RAM.

The Scenario

Imagine a computer running a web browser, video player, IDE, and a database simultaneously — all competing for limited RAM. When a new page must load and every frame is occupied, which page gets evicted? That decision is what SmartRAM lets you explore.

Page Replacement Algorithms

SmartRAM implements the three most important algorithms taught in Operating Systems courses.

FIFO
First In, First Out

Replace the page that has been in memory the longest. Simple to implement using a queue, but can suffer from Bélády's Anomaly.

Time: O(1)
Space: O(n)
Easy to implement Bélády's Anomaly
LRU
Least Recently Used

Replace the page that has not been accessed for the longest period. Tracks recently-used order — exploits temporal locality.

Time: O(n)
Space: O(n)
Good performance Requires tracking
OPT
Optimal (Clairvoyant)

Replace the page whose next use is farthest in the future. Provably optimal — fewest possible faults — but requires future knowledge.

Time: O(n·f)
Space: O(n)
Fewest faults Not implementable

Where Is Page Replacement Used?

The same memory-management problem appears everywhere — from kernel scheduling to browser caches.

Operating Systems

When physical RAM is insufficient, the OS manages pages between main memory and secondary storage (swap/pagefile).

Web Browsers

Browsers manage large amounts of active and inactive tab data and need efficient cache eviction strategies.

Database Systems

Database buffer pools cache disk pages in memory and must replace pages efficiently to sustain query performance.

Cloud Computing

Virtual machines and containers operate under memory constraints and require efficient page management across tenants.

Mobile Devices

Mobile OSes must manage limited RAM among multiple foreground and background applications, killing processes when necessary.

Embedded Systems

Devices with severely limited memory need aggressive and predictable memory utilization strategies.
