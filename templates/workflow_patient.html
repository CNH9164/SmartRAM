Patient Records Management

Introduction

Patient Records Management represents the part of a hospital information system responsible for organizing and accessing patient-related information. Conceptually, this includes registration details, demographic profiles, medical-history records and previous visit information. In SmartRAM, these categories are represented by synthetic memory-page requests rather than actual patient records.

How Operating System Concepts Are Applied

The simulation models how an application requests different memory pages while working with patient-related information. The configured RAM frames represent the limited physical memory available to the simulated workload.

  • A page hit occurs when a requested page is already in memory.
  • A page fault occurs when the requested page is absent from memory.
  • When all frames are occupied, a replacement algorithm chooses which existing page to remove.
  • FIFO replaces the page that entered memory earliest.
  • LRU replaces the page that has not been used for the longest time.
  • Optimal replaces the page whose next use is farthest in the future, using knowledge of the complete sequence as a theoretical benchmark.
How Page Replacement Can Improve Efficiency

Retaining useful pages in memory can reduce repeated page faults. A suitable replacement strategy may reduce the number of page faults for a given workload and memory capacity. Fewer page faults can reduce memory-related delays, although actual performance also depends on other system factors.
